# caffeine-vs-sleep

## Description
This project analyzes the relationship between caffeine consumption and sleep patterns, focusing on university students in Egypt. It examines whether higher caffeine intake is associated with reduced sleep duration and lower quality.

## Dateset
The data was collected through and online survey (126 responses) and includes information on sleep hours, sleep quality, caffeine intake and consumption habits.

## Methodology
The analysis was performed using Python in Google colab, applying descriptive statistics and visualizations to identify patterns and relationships.

## Key Findings
- Most participants consume moderate amounts of caffeine.
- Average sleep is around 7 hours.
- Higher caffeine intale is generally associated with less sleep.
- The relationship is moderate, not strong.

## Conclusion
Caffeine has an impact on sleep, but it is not the only factor affecting sleep patterns.
